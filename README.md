# Spotify-Analysis

Project Objective

In Today's digital music era understanding listening patterns is crucial for both users and streaming platforms. In this project, I created 3 dashboards regarding different insights for each section 

Dashboard-1 Overview
![image](https://github.com/user-attachments/assets/e72076d8-0aba-447c-87aa-811f362ad69f)

This Dashboard involves an analysis of Spotify Albums, Artists, Tracks data some of the insights covered are:
* Total Albums, Artists, Tracks
* Number of Albums, Artists, Tracks by Year
* Top 5 Albums, Artists, Tracks
* Latest Year vs Previous Year Analysis
* Year-Over-Year Analysis
