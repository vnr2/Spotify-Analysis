# Spotify-Analysis

Project Objective

In Today's digital music era understanding listening patterns is crucial for both users and streaming platforms. In this project, I created 3 dashboards regarding different insights for each section 

Dashboard-1: Overview
![image](https://github.com/user-attachments/assets/e72076d8-0aba-447c-87aa-811f362ad69f)

This Dashboard involves an analysis of Spotify Albums, Artists, Tracks data some of the insights covered are:
* **Total Albums, Artists, Tracks
* **Number of Albums, Artists, Tracks by Year
* **Top 5 Albums, Artists, Tracks
* **Latest Year vs Previous Year Analysis
* **Year-Over-Year Analysis

Dashboard-2: Listening Patterns
![image](https://github.com/user-attachments/assets/52a39085-aaba-4b4f-a642-92e068ac230b)

This Dashboard involves identifying peak listening times using a Heat map that visualizes patterns across hours and days with color intensity. Other insights covered are:
* Average Listening Time (min) vs Track Frequency
* High Frequency & High Listening Time - Most Engaging Tracks
* High Frequency & Low Listening Time - Short & Frequently played tracks
* Low Frequency & Low Listening Time - Less Popular tracks

Dashboard-3: Details View
![image](https://github.com/user-attachments/assets/0ac9d73f-7a37-4afc-8ff2-f46fc935cd77)

Created an interactive and dynamic grid to display key details like **Album Name, **Artist Name, and **Track Name on other relevant
